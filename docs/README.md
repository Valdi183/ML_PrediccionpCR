Documentación del caso.

- `decisiones.md`: qué pide la asignatura, las decisiones del modelo final y por qué, el umbral, el
  resultado en test y las referencias.
- `iteraciones.md`: cada iteración (hipótesis, resultado y decisión).
- `figuras/`: figuras de resultados (las `comparativa_*.png` las genera
  `notebooks/comparativa_modelos.ipynb`).
- `data/referencias.json`: lo que no sale de `results/` (referencia de la asignatura, Fridman et al.,
  licencia del dataset y URL del repositorio); `web/datos.json` lo copia de aquí.
